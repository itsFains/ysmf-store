YSMF HEADER TIKTOK UPDATE — V8
================================

This patch adds the YSMF TikTok link to the TOP-LEFT social navigation
on every main page.

TikTok:
https://www.tiktok.com/@ysmfapparel

UPDATED FILES
- index.html
- shop.html
- signature.html
- minimal.html
- about.html

NO CSS CHANGE IS REQUIRED.
Your current styles.css already supports the extra social link and keeps
the header icons sized correctly.

COPY / REPLACE
Replace the five HTML files in your current YSMF website with the files
from this package.

DO NOT REPLACE
- assets/styles.css
- assets/config.js
- assets/app.js
- any image assets

HEADER ORDER
Twitch
Instagram
TikTok

On smaller/mobile screens, your existing CSS hides the text labels and
keeps the compact social icons in the header.
